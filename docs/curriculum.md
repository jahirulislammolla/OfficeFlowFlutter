# Curriculum — ১২ সপ্তাহের Flutter Roadmap

## ১. ধীর শুরু, কিন্তু সম্পূর্ণ flow

প্রতি সপ্তাহে ৬-৮ ঘণ্টা ধরে শিখলে মোট প্রায় ১২ সপ্তাহে সাধারণ production-style beginner level শেষ হবে।

| সপ্তাহ | বিষয় | Project milestone |
|---|---|---|
| 1 | Environment, Dart basics | Flutter app run এবং Profile page shell |
| 2 | Widget ও layout | Dashboard screen |
| 3 | Navigation ও forms | Login ও navigation flow |
| 4 | HTTP networking | DummyJSON login ও employee/user list |
| 5 | JSON model ও error handling | Reliable API layer |
| 6 | State management | Provider/Riverpod দিয়ে data share |
| 7 | Persistence | Session ও attendance cache |
| 8 | Task/project modules | Filterable lists এবং detail pages |
| 9 | Responsive UI/theme | Mobile, tablet ও web layout |
| 10 | Testing | Unit/widget/integration tests |
| 11 | Accessibility ও polish | Search, pagination, loading, empty, error states |
| 12 | Capstone review ও build | Final demo, APK/web build |

## প্রতিদিনের routine

- ২০ মিনিট official documentation।
- ৩০ মিনিট হাতে Dart/Flutter code।
- ৩০ মিনিট project feature।
- ১০ মিনিট debugging/write notes।
- শেষে ৩টি নতুন বিহেভিয়ার শেখা কি না checklist করুন।
